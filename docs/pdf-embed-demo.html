PDF embedding — quick demo

Three ways to show the same PDF on a page, so you can compare before picking one.

1. <iframe> — browser's built-in PDF viewer

Zero setup. Uses whatever PDF viewer the browser already has. Full toolbar (zoom, search, page nav, download) comes for free on desktop.
Mobile note: most mobile browsers render this fine, but some Android browsers will trigger a download instead of showing it inline.

2. Plain link — most reliable, zero surprises

No embedding at all — just opens the PDF in a new tab (or downloads it, depending on the visitor's browser settings). Works everywhere, every time.
Open the full spec PDF ↗

3. PDF.js — in-page viewer with its own toolbar

Renders the PDF onto a canvas with page navigation and zoom controls that live inside your page's design, rather than the browser's native viewer chrome. More moving parts, nicest result.
